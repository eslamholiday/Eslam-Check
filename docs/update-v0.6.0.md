# Eslam Check 0.6.0 — تغييرات 5 أكتوبر 2026

الأساس: مصدر 0.5.2، رقم النسخة الجديدة 17، قاعدة البيانات 13.

- Eslam Bridge أعلى الرئيسية، ثم أرباح التذاكر: مجموع Discount الفعلي فقط. الدولار والدينار منفصلان. لا تدخل الفيز أو التسديدات أو بقية الأنواع في الأرباح.
- فلترة الرئيسية والمراجعة والتسديدات حسب العملة والفترة، وترتيب بتاريخ العملية صعودًا أو نزولًا.
- البحث يجمع الاسم والاسم البديل والهاتف والجواز والتذكرة وPNR ورقم العملية والمبلغ والتاريخ والخط والمسار، مع دعم الأرقام العربية وزر المسح.
- بطاقات العمليات تعرض التاريخ والمسار ودولة الفيزا إلى جانب معلوماتها السابقة. بطاقات التسديد تعرض رقم العملية والتاريخ والعملة والمبلغ والحالة.
- مجموع التسديدات منفصل لكل عملة، مع مجموع يومي وعدد النتائج وفق الفلاتر.
- المسافرون: زر × فقط في حقل البحث؛ لا تغيير في ترتيبهم أو علاقاتهم.
- مطابقة Base Fare بنفس الخط والمسار الموجّه والعملة وصنف المسافر، بهامش دولار واحد افتراضيًا. الأفضلية للتثبيت اليدوي ثم قرب السعر والأساسي عند توفره ثم قرب التاريخ وأحدثه. لا دمج للأسعار المختلفة بمتوسط، وتبقى الملاحظات ذات التواريخ المختلفة منفصلة. الصنف غير المعروف لا يُعامل كبالغ تلقائيًا.
- القواعد الرسمية لها الأولوية على القواعد المتعلّمة؛ تعلم الأسعار لا يعدل قواعد العمولة.
- حذف قاعدة العمولة مع حفظ نسختها للحالات التاريخية المتأثرة، بما فيها العمليات غير المراجعة. لا إعادة حساب أو تعديل مبالغ العمليات القديمة، ولا تطبيق القاعدة المحذوفة على العمليات الجديدة.
- مجموع الأرباح والبحث يشملان جميع السجلات، دون سقف العرض السابق البالغ 1000 عملية. فهرس البحث يُحضّر خارج واجهة العرض.

## التحقق

نجحت 26 حالة JUnit باستخدام Kotlin 2.1.10 محليًا، تشمل قواعد الفترات والهواتف ونسخ الفئات ومطابقة الأسعار وهامش الدولار وترجيح التاريخ وفصل العملات وحصر الربح بالتذاكر والبحث وترتيب التواريخ. نجح git diff --check.

لم يكتمل بناء Android أو اختبار الواجهة على جهاز. لم يُنتج APK جديد، ولم يُفحص توقيعه بعد. وافق المستخدم على رفع فرع التحديث وتشغيل البناء بتاريخ 5 أكتوبر 2026. لم يُدمج شيء في main.
